# lapinkyla.fi

A small site for Lapinkylä in Sirkka, Kittilä. Finnish is at `/`, `/puku`, `/asumus`, `/vene`, `/kalastus`, `/neulonta`, `/kielet`, `/valineet`, `/tyo`, `/nimi`, `/ruoka`, `/metsastys`, `/naiset`, `/uskonto`, `/rumpu`, `/leikit`, `/haat`, `/poro`, `/vero`, `/markkinat`, `/lapset`, `/hautaus`, `/koulu`, `/vuosi`, `/aseet`, `/elaimet`, `/linnut`, `/metallit`, `/puut`, `/kivet`, `/joet`, `/tunturit`, `/siida`, `/historia`, `/kylat`, and `/yhdistys`. English is under `/en`.

What may be used later, and what may not, is kept in `docs/sources.md`. That file is not published on the site.

Old addresses from the previous business site redirect to the matching homepage. Former photo and WordPress system addresses answer “gone”.

The site deploys from `main` on the separate Vercel project `lapinkyla`. It is not part of huts.fi.
